# /loop での定期実行

レビュー待ちの間、`/loop 10m /review-response` で本スキルを繰り返し実行できる（新しい指摘が付き次第対応する運用）。各イテレーションは通常モードと同じ手順でよい。判断対象の有無の確認がイテレーションを終わらせるかを決め、`pending` が空でないイテレーションでは毎回「PR 全体の読解」を行う。反応待ちスレッド（「行コメントスレッドの扱い」参照）の報告も、前イテレーションから顔ぶれが変わらなければ省略する — レビュアーの反応を待っている間ずっと同じ一覧が繰り返されるのを避けるため（単発実行での報告義務は変わらない）。レビュアーの立ち位置の報告（「判断対象の有無の確認」参照）も同じ理由で省略するが、条件は一段狭く、顔ぶれと各 `state` がどちらも変わらないときに限る — `state` が1つでも変われば出す（approve が付いた瞬間がまさに知りたい変化のため）。

**停止基準**（いずれかに該当したら /loop を停止し、理由を報告する）:
- PR がマージまたはクローズされた
- 「ユーザーに最終判断を委ねる場合」に該当する指摘が出た（ユーザーの応答なしにイテレーションを重ねても進展しないため）
- 鮮度確認サブ手順の停止条件に該当した（ユーザー介入が必要な状態のため）
