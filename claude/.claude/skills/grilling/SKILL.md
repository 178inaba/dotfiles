# /grilling

対象（計画・決定・アイデア）についてユーザーと共通理解に達するまで徹底的にインタビューし、曖昧さをモデルの推測で埋めたまま実装に進むのを防ぐ。[mattpocock/skills](https://github.com/mattpocock/skills) の grilling（MIT）を基にした翻案。

## 進め方

- 対象のあらゆる側面についてインタビューし、決定木の各分岐を辿る。決定間の依存関係は上流から一つずつ解消する（下流の質問は上流の回答が確定してから）
- 質問は AskUserQuestion で**一度に1つ**（複数質問の同時提示は読者を混乱させる）。各質問に自分の推奨回答を添え、推奨オプションを先頭に置く
- **判断は推測で埋めない**: 事実/判断の切り分けは質問の原則（グローバル CLAUDE.md）に従う。判断の質問は省略せず、回答を得てから先へ進む
- ユーザーが共通理解に達したと確認するまで、実装等の行動に移らない

## 完了時

- 固まった内容（決定事項・スコープ外・保留した判断）を要約して提示する
- 要約には `~/.claude/CLAUDE.md`「設計判断原則」の greenfield 判定（一致 / 妥協と失う性質 / ユーザー決定）を含める
- GitHub Issue 化する流れなら `/issue-draft` を案内する
