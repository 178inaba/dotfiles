# /grilling

対象（計画・決定・アイデア）についてユーザーと共通理解に達するまで徹底的にインタビューし、曖昧さをモデルの推測で埋めたまま実装に進むのを防ぐ。[mattpocock/skills](https://github.com/mattpocock/skills) の grilling（MIT）を基にした翻案。

## 進め方

- 対象を**決定木**として把握する。各決定は、それが決まって初めて問える下流の決定へ分岐する。**フロンティア**は、前提がすべて確定済みの未確定ノード（`open` と `assumed`）の集まり（下流の質問は上流の回答が確定してから）。同じラウンドで未確定の別の質問に回答が依存する質問は、そのラウンドではなく後のラウンドに属する（そうした依存が判明したらノードを依存先の下流へ移す。前提を木の入れ子だけで表しておけば、再計算がファイルだけで完結する）
- 1 ラウンドではフロンティアの質問をまとめて AskUserQuestion で聞く。1 回の呼び出しにつき 4 問まで（ツールの上限）で、フロンティアが 5 問以上なら複数回の呼び出しに分けて 1 ラウンドとする（同じラウンドの質問どうしに依存は無いので呼び出しの順序は問わない。すべての呼び出しの回答が揃った時点でラウンド完了）。各質問に自分の推奨回答を添え、推奨オプションを先頭に置く
- **事実は聞かずに自分で調べ、調べている間もラウンドを止めない**: 事実と判断の切り分けは「質問の原則」（グローバル CLAUDE.md）に従う。フロンティアの質問が環境の事実（コードベース・`gh`・文書）を要するとき、grep 1 回・ファイル 1 読みで済むならその場で調べる。それ以上かかるなら `model: "sonnet"` の Explore サブエージェントをバックグラウンドで起動し（「サブエージェントのモデル選択」— グローバル CLAUDE.md）、その事実の下流の質問だけを待たせて残りのフロンティアは今のラウンドで聞く
  - 残りのフロンティアが空でサブエージェントの報告待ちになったら、**ターンを終えて完了通知での再開を待つ**
- 決定木はセッションの scratchpad 直下へ固定名 `grilling-tree.md` で保持する（コンテキストのコンパクション後にパスを知らなくても再発見でき、フロンティアの再計算と完了判定を機械的に行えるようにするため）。**最初のラウンドの前に作成し、各ラウンドの後・各サブエージェントの報告の後に必ず更新する**。ノードごとに 1 行の markdown アウトラインで足り、これ以上のスキーマは要らない:

  ```markdown
  - 認証方式: settled — セッション Cookie
    - Cookie の寿命: open
    - CSRF 対策: investigating — Explore（既存ミドルウェアの調査）
  - レート制限: assumed — 既存の 60 req/min を踏襲
  ```

  - `settled`（回答そのものを併記）/ `open` / `investigating`（待っているサブエージェントを併記。報告が届いたら、事実だけで決まるノードは `settled` に、判断が残るノードは `open` にする）/ `assumed`（既定値・慣習の踏襲を聞かずに自分で埋めたもの。ユーザーが決めるべき判断には使わない。完了条件を満たさないので、確認して `settled` にする）の 4 状態で記録する
  - 回答が確定済みのノードを無効化した場合は、そのノードとその下流をすべて `open` に戻す
- ファイルを更新したら**フロンティアを再計算する**: `open` と `assumed` のノードのうち、前提がすべて `settled` のものを列挙する。それが次のラウンドの質問になる
- **判断は推測で埋めない**: 判断の質問は省略せず、回答を得てから先へ進む
- **フロンティアが空になったら完了**（決定木ファイルの全ノードが `settled` で、`assumed`・`investigating` のものが 1 つも無い状態）。その状態を下記の要約とともに提示し、ユーザーが共通理解に達したと確認するまで、実装等の行動に移らない

## 完了時

- 固まった内容（決定事項・スコープ外・保留した判断）を決定木ファイルから要約して提示する
- 要約には `~/.claude/CLAUDE.md`「設計判断原則」の greenfield 判定（一致 / 妥協と失う性質 / ユーザー決定）を含める
- GitHub Issue 化する流れなら `/issue-draft` を案内する
