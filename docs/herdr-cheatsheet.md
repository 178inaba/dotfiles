# herdr チートシート

`prefix` は `ctrl+b`。

## 設定・ヘルプ

| キー | 説明 |
|-----|------|
| `prefix + s` | 設定画面を開く |
| `prefix + ?` | キー一覧（ヘルプ）を表示 |
| `prefix + R` | 設定を再読み込み |
| `prefix + q` | デタッチ（一時的に離脱） |

## ワークスペース操作（tmux のセッションに相当）

| キー | 説明 |
|-----|------|
| `prefix + N` | 新しいワークスペースを作成 |
| `prefix + W` | ワークスペース名を変更 |
| `prefix + w` | 一覧から選んで切り替え |
| `prefix + D` | 現在のワークスペースを閉じる |
| `prefix + g` | エージェント・ペインを選んで直接移動 |

## タブ操作（tmux のウィンドウに相当）

| キー | 説明 |
|-----|------|
| `prefix + c` | 新しいタブを作成 |
| `prefix + T` | タブ名を変更 |
| `prefix + n` | 次のタブに移動 |
| `prefix + p` | 前のタブに移動 |
| `prefix + 1-9` | 指定番号のタブに移動 |
| `prefix + X` | 現在のタブを閉じる |

## ペイン操作（画面分割）

### 基本分割

| キー | 説明 |
|-----|------|
| `prefix + v` | 左右に分割 |
| `prefix + -` | 上下に分割 |
| `prefix + x` | 現在のペインを閉じる |

### ペイン間移動

| キー | 説明 |
|-----|------|
| `prefix + h` | 左のペインに移動 |
| `prefix + j` | 下のペインに移動 |
| `prefix + k` | 上のペインに移動 |
| `prefix + l` | 右のペインに移動 |
| `prefix + Tab` | 次のペインに移動 |
| `prefix + Shift+Tab` | 前のペインに移動 |

### ペインの配置・サイズ

| キー | 説明 |
|-----|------|
| `prefix + H` | 左のペインと入れ替え |
| `prefix + J` | 下のペインと入れ替え |
| `prefix + K` | 上のペインと入れ替え |
| `prefix + L` | 右のペインと入れ替え |
| `prefix + z` | 全画面表示の切り替え |
| `prefix + r` | サイズ変更モード |

## サイドバー

| キー | 説明 |
|-----|------|
| `prefix + b` | サイドバーの表示を切り替え |
